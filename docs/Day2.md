## Engineering Standards

- Deterministic logic must remain deterministic
- AI must not make final compliance decisions
- Every important result should have evidence
- Core functionality requires tests
- Synthetic fixtures only
- No secrets or production data
- No unnecessary dependencies
- No premature frontend/deployment work

---

## Day 2 Definition of Done

A feature is complete only when:

1. Implementation exists
2. Tests pass
3. Edge cases are considered
4. Example input/output exists
5. Documentation is updated
6. Code is ready for review
