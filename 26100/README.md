# PS 26100

Project workspace for the PS 26100 bid compliance verification proof of concept.

## Structure

- `docs/` - technical design and project documentation
- `src/` - implementation modules, to be developed after the design phase
- `tests/` - fixtures and automated tests
- `data/` - reproducible project datasets

The Day-1 technical design is in [docs/day-1-technical-design.md](docs/day-1-technical-design.md).
